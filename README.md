# ONEhub Desktop Updates

This public repository contains only signed ONEhub Desktop update artifacts:

- `latest.json` for the in-app updater
- the current Windows installer
- its Tauri updater signature

The ONEhub Desktop source code remains private in `LBTown85/onehub-desktop`. Do not place application source, credentials, signing keys, or internal documentation in this repository.

The current installer is also published under [Releases](../../releases/latest).
